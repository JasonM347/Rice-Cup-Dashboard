Rice Cup Predictor

Hi Marvin,

I built a free live dashboard for this weekend's Main Event that anyone can open on their phone, no sign-in needed. It reads the brackets straight from your Challonge pages and turns them into match odds and a running schedule.

Open the dashboard jasonm347.github.io/Rice-Cup-Dashboard

What's on it

  • Every match in the Main Event, Hard Luck, Women's and Junior brackets, with the favourite and win chance for each player.
  • Player ratings from FargoRate and league CSR, with CSR converted to the Fargo scale using the MPA division table.
  • A suggested fair race for every match.
  • An estimated start time and table for each match on 11 tables (winners side race to 5, losers side race to 4).
  • Each player's chance to make the top 16 and to win the event, updated as results come in.

It's an unofficial fan page and doesn't change anything on Challonge. It only reads the brackets.

One favour: a Challonge API key

To refresh itself every 15 minutes without my computer running, the page needs to read your brackets through Challonge's official API. Challonge only lets a key read tournaments its own account runs, so the key has to come from the account that owns the Rice Cup brackets. It takes about five minutes.

  1. Sign in at challonge.com with the account that runs the Rice Cup brackets.
  2. Go to connect.challonge.com (Challonge Connect, their developer portal). You can also get there from Settings → Developer API on challonge.com.
  3. Click New Application and fill in the form:
    Application's name
    Rice Cup Dashboard
    Description
    Read-only refresh of the Rice Cup brackets for the public predictor page
    Website
    https://jasonm347.github.io/Rice-Cup-Dashboard/
    Redirect URI
    https://jasonm347.github.io/Rice-Cup-Dashboard/
    The redirect address isn't used; the form just requires one.
  4. Click Save. Open the new application and copy the credentials it shows. If it offers an API v1 key, that's the one I need. If it shows a Client ID and Client Secret instead, copy both.
  5. Send them to me privately, by text or direct message. Please don't post them in a group chat or a shared email thread.

What happens with the key

Read only. The page only reads the Main Event and Hard Luck brackets. It never creates, edits or reports anything on Challonge.

Stored safely. I add it as an encrypted secret on GitHub, where the site is hosted. It never appears on the page or in any logs.

Within the free plan. Challonge's free API allows 500 requests a month. The page only refreshes during play hours, which uses roughly 350 this weekend. If you already use the Challonge API for something else this month, let me know and I'll slow it down.

Easy to switch off. Delete the application on Challonge Connect any time and the key stops working right away. I'd suggest deleting it after Sunday.

If you'd rather not share a key, no problem. The dashboard will keep updating from my computer during the event instead.

Thanks, and good luck running the weekend!
